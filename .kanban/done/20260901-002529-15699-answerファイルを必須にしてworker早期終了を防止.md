## Task

# 不具合
`herdr-agent-worker.sh` がHerdrの一時的な idle/done 判定だけでagent完了とみなし、`.kanban-answer.md` が無いままpaneを閉じる。実例ではworkerが最初のgit log実行中なのに20秒で終了扱いされ、reviewerが未着手score 0としてworkerを丸ごと再実行した。

# 修正範囲
- `herdr-agent-worker.sh` のworker/reviewer/resolver完了判定だけを修正する。
- card id・role・attemptごとのanswer path/metadataをpromptへ渡し、正しい `.kanban-answer.md` の存在と内容を完了sentinelにする。
- idle/doneでもanswerが無ければpaneを閉じない。agent状態が安定し、answerがatomicに完成するまでbounded waitする。
- answer未作成のままagentが終了/timeout/消失した場合は明確なinfrastructure errorで終了し、terminal status lineを成果として返さない。
- alternate-screenの`agent read`を最終回答の代用にしない。diagnostic tailとしてだけ扱う。
- blocked判定は実permission/questionと実行中表示を区別し、実行中shellを勝手にEnter/closeしない。
- pane closeはanswer読取・検証後。cleanup raceをなくす。

# テスト
- mock Herdrで、一時idle→再working→answer作成、shell実行中のfalse blocked、idleだがanswerなし、agent消失、正しいanswer完成を再現する。
- 最初のcommand中にpaneが閉じられないこと、answer完成後だけstdoutへ返しcloseすることをassertする。
- worker/reviewer/resolverとClaude/Codexを対象にする。
- targeted test + fast suiteを各1回。full suiteは最終gateで1回だけ。日本語commit、pushなし。
