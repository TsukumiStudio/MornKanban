## Task

# 目的
後から「いつ、どのcardの、worker/reviewer/resolverを、どのHerdr agent/paneへ投げ、いつ何状態になったか」を追跡できるようにする。現在はcard History、Herdr server log、Gitを手作業で時刻突合する必要があり、`.kanban/wt/*.log`も大半が空。

# 実装
- dispatcherからwrapperへ card_id、title、role、worker attempt/review infra attemptを明示的に渡す。
- project-localなbounded JSONL等へ次を記録: timestamp、card_id、role、attempt、backend/model、agent_name、pane_id、event(start/prompt/working/blocked/answer_ready/exit/close/error)、duration、error category。
- prompt本文、answer本文、command全文、秘密値、credentialは記録しない。
- card Historyにもagent/pane/correlation idとphase summaryを短く残す。
- log rotation/size上限を設け、atomic appendと並列worker安全性を保証する。
- monitorでcard timelineをproject別に読み取り専用表示する。過去log欠落時も落ちない。
- agent名/pane名にcard id/roleを含め、終了後もJSONLから追跡可能にする。

# テスト
- 2card×worker/reviewer/resolverの並列mockで相関が交差しないこと、rotation、crash途中、秘密値非記録を検証する。
- monitor API/UIのtimelineとread-only制約を検証する。
- targeted + fast各1回、full最終1回。日本語commit、pushなし。
