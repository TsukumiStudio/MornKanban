## 目的
gui/static/app.js を「セットアップウィザード」ロジックへ全面的に書き換える (素の JS、ライブラリ禁止)。
ボードポーリング・カード追加・ポリシー編集・モーダル・秘書/ディスパッチャ起動のコードは**全て削除**。

## DOM 契約 (index.html に存在する id)
dep-badges / step-cli / install-cli-status / btn-install-cli / step-skill / install-skill-status /
btn-install-skill / step-projects / project-path / btn-add-project / project-list (ul) / step-next / toast

## API 契約
- GET /api/status → {"deps":{"herdr","claude","codex","python3"...bool},"install":{"cli":bool,"skill":bool},"repo":str,"herdr_env":bool}
- POST /api/install/cli → {"ok":true,"in_path":bool}
- POST /api/install/skill {"force":bool任意} → {"ok":true,"path":str} / 409 {"ok":false,"error":"already installed..."}
- GET /api/projects → {"projects":[{"path","name","has_kanban"}]}
- POST /api/projects {"path"} / POST /api/init {"path"}
- エラーは {"ok":false,"error":str} または非2xx → toast 表示

## 挙動
- 起動時に refresh(): /api/status と /api/projects を取得して描画
- dep-badges: herdr/claude/codex を span.ok/.ng で表示。herdr か claude が無ければ toast で警告
- CLI ステップ: install.cli により status span に「導入済み」(.ok)/「未導入」(.ng)。ボタンで POST →
  in_path が false なら「~/.local/bin に PATH を通してください」を toast → refresh
- スキルステップ: 同様。409 が返ったら confirm() で「上書きしますか」と聞き、OK なら {"force":true} で再送
- プロジェクト: btn-add-project で POST /api/projects → refresh。project-list の各 li は
  「name (path)」+ has_kanban なら「導入済み」バッジ、未導入なら「kanban init」ボタン (押すと POST /api/init → refresh)
- 両ステップ完了 (install.cli && install.skill) で該当 section に .done を付与
- toast(msg): 3秒で自動非表示

## 完了条件・検証
- node --check gui/static/app.js が通る
- fetch 以外のグローバル依存なし。DOMContentLoaded 後に初期化
