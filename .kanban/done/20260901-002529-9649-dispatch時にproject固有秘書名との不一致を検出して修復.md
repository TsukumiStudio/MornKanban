## Task

# 不具合
current live agent名は`secretary`だが、dispatchはproject resolverから`secretary-mornkanban`を通知先に設定している。`herdr agent get secretary-mornkanban`はagent_not_foundとなり、done/failed通知が黙って失われる。project固有名機能を導入前から継続しているsessionで発生する。

# 修正
- `kanban-secretary.sh dispatch`開始前に、current paneのlive agent名とresolved secretary nameを実測する。
- 不一致なら、安全にcurrent agentをresolved名へrenameして同一性を確認する。別agentが使用中ならdispatchを開始せず、衝突とoverride方法を明示する。
- agent未検出・pane不一致時も通知不能のdispatcherを開始しない。
- notify hookは送信前にtarget存在を確認し、失敗を黙殺せずproject-local診断History/logへ残す。dispatcher本体は落とさない。
- bootstrap済み旧session、project alias/name変更、別project同時秘書、explicit overrideを扱う。

# テスト
- live名secretary→resolved secretary-projectへのmigration、衝突、別pane、stale marker、通知成功/失敗をmock Herdrで検証する。
- targeted + fast各1回、full最終1回。日本語commit、pushなし。
