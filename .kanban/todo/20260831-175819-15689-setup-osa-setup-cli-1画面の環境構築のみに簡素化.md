## 目的
gui/setup_osa.py (macOS ダイアログ) と gui/setup_cli.py (CLI) を「環境構築のみ・1画面完結」に書き換える。
ロジックは gui/setup_core.py (別カードが同時改修中) を使う。契約:
check_deps()->dict / cli_installed()->bool / skill_installed()->bool / in_worktree()->bool /
run_setup()->list[str] (CLI symlink とスキル導入をまとめて冪等実行し結果メッセージ群を返す)

## setup_osa.py (書き換え)
- ダイアログは最大2枚だけ。メニューループ禁止:
  1枚目: display dialog で現在の状態をまとめて表示
    (deps: herdr ✓ claude ✓ codex ✓ / kanban CLI: 導入済み|未導入 / スキル: 導入済み|未導入 と、
     「導入後はプロジェクトのペインで claude に『kanban の秘書として待機して』」の案内)
    ボタン: {"閉じる", "セットアップ実行"} (default: セットアップ実行)。既に両方導入済みならボタンは {"閉じる"} のみ
  2枚目 (実行した場合のみ): run_setup() の結果メッセージと実行後の状態を表示、ボタン {"OK"}
- キャンセル/閉じる (osascript exit 1) は正常終了扱い。macOS 以外・osascript 不在は stderr + exit 2
- プロジェクト関連の操作・ダイアログは持たない

## setup_cli.py (書き換え)
- 状態サマリを print → TTY なら「セットアップを実行しますか? [y/N]」を1回だけ聞き、y なら run_setup() の
  結果を print。非TTY (stdin 閉鎖等) はサマリ表示のみで exit 0。メニューループ禁止
- プロジェクト関連の操作は持たない
