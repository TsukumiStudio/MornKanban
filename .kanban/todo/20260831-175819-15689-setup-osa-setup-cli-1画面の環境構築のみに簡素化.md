  1枚目: display dialog で現在の状態をまとめて表示

     「導入後はプロジェクトのペインで claude に『kanban の秘書として待機して』」の案内)

- プロジェクト関連の操作は持たない

- grep で両ファイルに project/init_project の残骸が無い。osascript ダイアログはこの検証では開かない
