## 目的
kanban-gui.sh を「利用可能なフロントを自動選択して起動する」ものに書き換え、README の GUI 節を更新する。
フロント: gui/setup_gui.py (tkinter) / gui/setup_osa.py (macOS osascript) / gui/setup_cli.py (対話CLI) —
いずれも別カードが同時作成中。各フロントは「自分が動けない環境なら exit 2」という規約。

## kanban-gui.sh の仕様 (bash 3.2, set -euo pipefail)
1. python3 が無ければエラー終了
2. python3 -c "import tkinter" 2>/dev/null が通れば exec python3 "$REPO/gui/setup_gui.py"
3. 通らず、uname が Darwin かつ command -v osascript があれば exec python3 "$REPO/gui/setup_osa.py"
4. どちらも駄目なら exec python3 "$REPO/gui/setup_cli.py"

## README「## GUI」節の書き換え (他の節は触らない、英語 5〜7 行)
- ./kanban-gui.sh opens the best available setup frontend: a small tkinter window,
  native macOS dialogs (osascript) when tkinter is missing, or an interactive CLI wizard anywhere else
- Zero extra installs — python3 plus whatever the OS already ships
- Buttons/menu: install the kanban CLI, install the Claude Code skill, register projects + kanban init
- Day-to-day operation stays with the secretary (Secretary Bootstrap)
