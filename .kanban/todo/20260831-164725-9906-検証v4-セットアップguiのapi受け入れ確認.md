## Task

## 目的
セットアップ専用に改稿された GUI (gui/server.py 等) を API レベルで検証し、gui/VERIFY.md を**全面的に書き直す**。
コードの修正はしない。レポートは段階書き込み (項目ごとに追記)。**ブラウザ操作ツールは絶対に使わない**。

## 手順
1. gui/VERIFY.md を新規内容で作り直し「セットアップGUI 検証」見出しと開始時刻を書く
2. MORNKANBAN_GUI_PORT=8803 python3 gui/server.py をバックグラウンド起動 (最後に必ず kill)
3. curl 検証 (各項目の PASS/FAIL とレスポンス断片をその都度追記):
   - GET /api/status → deps{herdr,claude,codex,python3} と install{cli,skill} と repo と herdr_env を含む
   - GET /api/board が 404 (旧エンドポイントが削除されている)。/api/policy と /api/card も 404
   - POST /api/install/cli → ok:true かつ ~/.local/bin/kanban がシンボリックリンクとして存在
   - POST /api/install/skill (force なし) → **409 が返ること** (この環境にはスキル導入済みのため。
     force での上書きは絶対にしない — 既存スキルは別システム生成物)
   - mkdir -p /tmp/kanban-gui-verify4 のうえ POST /api/projects → ok:true、
     POST /api/init → /tmp/kanban-gui-verify4/.kanban 生成、GET /api/projects に has_kanban:true で載る
4. サーバ kill → pgrep -f gui/server.py が 0 件であることを追記
5. 末尾に総合判定 (PASS/FAIL)

## 完了条件
- gui/VERIFY.md がセットアップGUI 検証の内容で全項目 PASS/FAIL と総合判定を持つ
- pgrep -f gui/server.py が 0 件
