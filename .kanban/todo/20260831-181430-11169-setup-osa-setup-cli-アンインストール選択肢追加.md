## 目的
gui/setup_osa.py と gui/setup_cli.py にアンインストール操作を追加する。1画面完結の構造は維持。他ファイルは触らない。

## 契約 (setup_core.py に実装済み)
run_uninstall() -> list[str]

## setup_osa.py
- 1枚目の display dialog のボタンを {"閉じる", "アンインストール", "セットアップ実行"} の3つにする
  (osascript の display dialog はボタン最大3つ)。default はセットアップ実行のまま
- 「アンインストール」選択時は run_uninstall() を実行し、2枚目のダイアログに結果と実行後状態を表示
- ダイアログ最大2枚・ループ禁止の構造は変えない

## setup_cli.py
- TTY 時の質問を「[y=セットアップ / u=アンインストール / N=何もしない]」の1回に変更。
  u なら run_uninstall() の結果を print。非TTY はサマリのみ exit 0 のまま

## 完了条件・検証
- python3 -m py_compile gui/setup_osa.py gui/setup_cli.py
- python3 gui/setup_cli.py </dev/null が exit 0 (インストール/アンインストールは走らない)
- echo n | python3 gui/setup_cli.py が exit 0、echo u | python3 gui/setup_cli.py は run_uninstall が
  worktree ガードで refused を返す旨の出力で exit 0
- osascript ダイアログはこの検証では開かない
