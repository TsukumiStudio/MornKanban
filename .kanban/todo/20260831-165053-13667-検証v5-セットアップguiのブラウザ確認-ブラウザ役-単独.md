## Task

## 目的
あなたはこのボードで唯一の「ブラウザ役」エージェント (同時に1体だけのルールで単独実行中)。
セットアップ GUI を実際にブラウザで開いて操作し、結果を gui/VERIFY.md の末尾に「## ブラウザ検証」節として追記する。
コードの修正はしない。

## 手順
1. MORNKANBAN_GUI_PORT=8804 python3 gui/server.py をバックグラウンド起動 (最後に必ず kill)
2. ブラウザ操作ツール (claude-in-chrome / mcp__claude-in-chrome__*) で http://127.0.0.1:8804/ を開く。
   ツールへの接続に60秒以上かかる・エラーになる場合は即諦め、その旨を VERIFY.md に記録して手順4へ
3. 確認して VERIFY.md に段階追記:
   - ページ見出しに Setup の文言、依存バッジ (herdr/claude/codex) が表示される
   - CLI ステップ・スキルステップのステータス表示が見える
   - **注意: 「Claude Code スキルを導入」ボタンと「kanban CLI をインストール」ボタンは絶対にクリックしない**
     (前者は confirm ダイアログがブラウザをブロックする。後者は worktree からの実行で環境を壊した前例がある)
   - 先にシェルで mkdir -p /tmp/kanban-gui-verify5 を実行し、プロジェクト欄に /tmp/kanban-gui-verify5 を
     入力して追加 → 一覧に現れる → 「kanban init」ボタンを押す → バッジが導入済みに変わる →
     シェルで /tmp/kanban-gui-verify5/.kanban の存在を確認
   - スクリーンショットを撮り、見た目の崩れの有無を文章で記録
4. 開いたタブを閉じ、サーバを kill (pgrep -f gui/server.py が 0 件)
5. VERIFY.md 末尾のブラウザ節に判定 (PASS/FAIL/未実施) を書く

## 完了条件
- gui/VERIFY.md に「## ブラウザ検証」節があり、実施内容または未実施理由と判定が書かれている
- pgrep -f gui/server.py が 0 件
