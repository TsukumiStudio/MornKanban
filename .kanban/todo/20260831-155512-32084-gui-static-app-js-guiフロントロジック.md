## Task

## 目的
MornKanban ローカル GUI のフロントロジック `gui/static/app.js` を新規作成する (素の JS、ライブラリ禁止)。
index.html / server.py は別カードが同時に作っているため参照できない。以下の契約だけを頼りに実装する。

## DOM 契約 (index.html に存在する id)
dep-badges / project-list (select) / project-path (input) / btn-add-project / btn-init /
btn-secretary / jobs-input / btn-dispatch / tab-board / tab-policy / view-board / view-policy /
col-todo col-doing col-review col-done col-failed (ul) / card-title / card-body / card-backend (select) /
card-model / btn-add-card / policy-editor (textarea) / btn-save-policy /
card-modal (hidden div) / modal-content (pre) / modal-close / toast (hidden div)

## API 契約 (同一オリジン)
- GET /api/status → {"deps":{"herdr":bool,"claude":bool,"codex":bool,"kanban":bool},"herdr_env":bool,"repo":str}
- GET /api/projects → {"projects":[{"path","name","has_kanban"}]}
- POST /api/projects {"path"} / POST /api/init {"path"} / GET /api/policy?path= → {"content"} /
  PUT /api/policy {"path","content"} / GET /api/board?path= → {"states":{todo:[{id,title,attempts,file}],...}} /
  GET /api/card?file= → {"content"} / POST /api/card {"path","title","body","backend","model","threshold":""} /
  POST /api/secretary {"path"} / POST /api/dispatch {"path","jobs"}
- 失敗レスポンスは {"ok":false,"error":str} または非2xx。エラーは toast に表示

## 挙動
- 起動時: /api/status → dep-badges に各依存を span (class ok/ng) で表示。herdr_env が false なら
  「Herdr ペイン内で起動してください (秘書/ディスパッチャ操作不可)」を toast 表示し btn-secretary/btn-dispatch を disabled
- /api/projects → project-list を構築 (has_kanban でない項目は「(未init)」表示)。選択変更で board と policy を再読込
- btn-add-project: project-path の値を POST /api/projects → 一覧更新して選択
- btn-init: 選択中プロジェクトへ POST /api/init → board 再読込
- board: 選択中プロジェクトを 3 秒ごとにポーリングして5列を再描画。カード li は「title (attempts)」、クリックで
  GET /api/card → modal-content に表示し card-modal を表示。modal-close とオーバーレイクリックで閉じる
- btn-add-card: title 必須。POST /api/card (threshold は空文字) → 入力欄クリア、board 再読込
- btn-secretary / btn-dispatch: 確認なしで POST。成功時 toast に pane 名を表示
- tab-board / tab-policy で view の hidden を切替。policy 表示時に GET /api/policy、btn-save-policy で PUT
- toast(msg): 3秒表示して自動で隠す共通関数を作る

## 完了条件・検証
- node --check gui/static/app.js が通ること
- fetch 以外のグローバル依存なし。DOMContentLoaded 後に初期化
