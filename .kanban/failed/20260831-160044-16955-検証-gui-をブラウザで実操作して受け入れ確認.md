## Task

## 目的
マージ済みの MornKanban ローカル GUI (kanban-gui.sh / gui/server.py / gui/static/*) を実際に起動・操作して
受け入れ基準を確認し、結果レポート `gui/VERIFY.md` を書く。**コードの修正はしない** (不具合は VERIFY.md に記録するだけ)。

## 手順
1. サーバ起動: MORNKANBAN_GUI_PORT=8776 python3 gui/server.py をバックグラウンド起動 (検証後に必ず kill)
2. API 検証 (curl):
   - GET /api/status が deps/herdr_env/repo を含む JSON
   - mkdir -p /tmp/kanban-gui-verify のうえ POST /api/projects {"path":"/tmp/kanban-gui-verify"} → ok:true
   - POST /api/init 同 path → /tmp/kanban-gui-verify/.kanban が生成される
   - GET /api/policy?path=... が KANBAN.md の中身を返す。PUT /api/policy で内容を書き換え、GET で往復一致
   - POST /api/card {"path":...,"title":"verify","body":"test","backend":"","model":"","threshold":""} → ok:true
   - GET /api/board?path=... の states.todo に1枚見え、GET /api/card?file=<そのfile> が本文を返す
3. ブラウザ検証 (Chrome 操作ツールが使えるなら): http://127.0.0.1:8776 を開き、
   - 依存バッジが表示される / プロジェクト欄に /tmp/kanban-gui-verify を追加・選択できる
   - ボード5列が表示され、カード追加フォームから追加したカードが todo 列に現れる
   - カードをクリックするとモーダルに本文が出る / ポリシータブで編集・保存できる
   - スクリーンショットの内容を VERIFY.md に文章で記録 (画像添付は不要)
   Chrome ツールが使えない場合はその旨を VERIFY.md に明記し API 検証のみとする
4. 注意: /api/secretary と /api/dispatch は実行しない (エージェントやペインが増殖するため)。ボタンの存在確認まで
5. 後片付け: サーバ kill、/tmp/kanban-gui-verify は残してよい

## 完了条件
- gui/VERIFY.md が存在し、上記の各項目に PASS/FAIL と根拠 (レスポンス断片や画面の観察) が書かれていること
- FAIL があっても正直に記録されていれば完了 (隠したら不合格)
